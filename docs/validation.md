## 本项目新增内容

- 统一安装器：预检、原子替换文件、校验 unit、启用与启动两项服务。
- MCU 的 systemd 启动通知：握手与首个心跳成功后发送 `READY=1`。
- USB 服务失败重试配置，保留原有 GPIO 操作流程。
- mock 单元测试和 GitHub Actions：覆盖 MCU 协议失败、通知顺序、USB 位保护、重复执行及安装失败行为。

本地测试不访问真实 I²C，也不等同于目标板 systemd 及重启验证。CI 的 systemd 配置校验不启动硬件服务。

## 目标板验收清单

1. 安装退出码为 0，两个 unit 均为 enabled 和 active。
2. 本次启动中 MCU 身份、启用回读、握手回读及首个心跳通过，后续每约 20 秒持续写入。
3. 持续观察不少于 30 分钟：boot ID 不变、uptime 增加、MainPID 不变且 NRestarts=0。
4. 两个 USB-A 口分别完成真实设备枚举与输入测试，核对 USB 服务日志和状态记录。
5. 安排受控重启，确认 boot ID 改变，无需人工启动两项服务，重复检查新启动日志及至少 30 分钟观察。

若 USB 日志显示由内核驱动接管，应验证内核端供电行为；服务 active 只能说明跳过执行成功，不能证明插口有电。
